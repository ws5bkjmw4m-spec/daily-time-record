# 日常刻度 · 時間紀錄

一個以直向時間表記錄整天活動的網頁程式。每一天從當天 05:00 開始，到隔天 05:00 結束；時間標示由 05:00 向下排到隔天 04:00。

## 使用方式

在瀏覽器開啟 `index.html` 即可使用，不需要安裝套件或啟動後端。

1. 用上方箭頭前後換天，或點日期選擇指定日期。
2. 按「新增事件」，輸入開始時間、結束時間與做過的事。
3. 時間可輸入 `8:05`、`0805` 或 `0928`。例如 08:05～09:28 會顯示為 83 分鐘的色塊。
4. 點色塊或下方事件清單可編輯。可取消編輯、清除事件，並復原剛清除的事件。
5. 按「匯出 .md」，下載目前日期已儲存的事件，檔名為 `時間紀錄-YYYY-MM-DD.md`。

00:00～04:59 視為隔天，結束時間 05:00 視為隔天 05:00。重疊事件會並排顯示，摘要中的已記錄時間不重複計算重疊時段。

## 資料儲存

紀錄保存在目前瀏覽器的 localStorage，不會上傳到 GitHub。不同瀏覽器、裝置或網址使用各自的紀錄。清除瀏覽器資料可能移除紀錄，頁面下方另有 JSON 備份下載按鈕。

Markdown 匯出只包含已儲存的事件。舊版每小時紀錄會在同一儲存位置讀取為一小時事件，舊版資料仍保留。
